<h3>Game Instructions</h3>
<ol>
  <li>There is one tile hiding a pumpkin. The rest will uncover a ghost.</li>
  <li>At the start of the game, you will have 5 attempts to find the pumpkin. Uncover one tile at a time by clicking or tapping on any of your choice.</li>
  <li>If you find all ghosts within your 5 attempts, a pop-up window will announce: "💀 The ghosts win!" You can close the pop-up and select the "Play Again" button to start over.</li>
  <li>If you find the pumpkin within the 5 attempts, a pop-up window will announce: "🎉 You found the haunted pumpkin!" You can close the pop-up and select the "Play Again" button to start over.</li>
  <li>Note that when you start over, the pumpkin will move to a different random tile.</li>
</ol>
